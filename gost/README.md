# Проект ГОСТ

Публикуемые Markdown-исходники глав находятся в `input/pagecontent/gost-*.md`.
Они одновременно используются как страницы сайта RuCore и как исходники
единого DOCX.

Порядок сборки DOCX описан в `WORKFLOW.md`.

Каталог `gost-local/` предназначен для локальных справочных материалов и
промежуточных файлов. Он исключен из Git и не публикуется.
