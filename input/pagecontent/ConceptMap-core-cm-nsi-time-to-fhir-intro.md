## Применение

Карта задаёт общий перевод кодов НСИ в семь кодов [UnitsOfTime FHIR R5](https://hl7.org/fhir/R5/valueset-units-of-time.html) для `Timing.repeat.periodUnit` и `durationUnit`. Для остальных Quantity можно сохранять исходное кодирование НСИ.

| Код НСИ | Единица | Код UCUM |
|---|---|---|
| 21 | Секунда (с) | `s` |
| 22 | Минута (мин) | `min` |
| 23 | Час (ч) | `h` |
| 24 | День (сут) | `d` |
| 520 | Неделя (нед) | `wk` |
| 521 | Месяц (мес) | `mo` |
| 522 | Год (год) | `a` |

Например, период «12 ч» с кодом НСИ `23` преобразуется в:

```json
{"repeat": {"period": 12, "periodUnit": "h"}}
```

Число сохраняется. Месяц и год не заменяются фиксированным числом дней: карта сопоставляет единицы, а не вычисляет даты расписания. Для календарного расписания правила вычисления дат задаёт приложение.

Источник кодов — [НСИ МЗ РФ, единицы измерения](https://nsi.rosminzdrav.ru/dictionaries/1.2.643.5.1.13.13.11.1358). Все семь пар подтверждены полем `UCUM` в [архивной копии справочника](https://beta.apicrafter.ru/tables/nsimz/4416) (дата обновления каталога 25.10.2021; проверено 24.09.2026). Исходные строки и контрольная сумма выгрузки сохранены в репозитории, `reports/time-unit-map-2026-09-24`. Используется поле `ID`, а не служебное `SYS_RECORDID`. Номер редакции НСИ для этой копии не установлен, поэтому версия источника в карте не заявлена. Версия ConceptMap — версия карты RuCore, не НСИ.

Направление перевода — из canonical CodeSystem RuCore в UCUM. При исходном `urn:oid:1.2.643.5.1.13.13.11.1358` преобразователь предварительно распознаёт систему по NamingSystem и выбирает canonical URI; NamingSystem сам по себе не выполняет перевод. Для иных редакций НСИ применимость проверяется по смыслу исходного кода. Если соответствия нет, преобразователь сообщает об этом; исходный код нельзя молча выдать за UCUM.

Это предложение для обсуждения группой. Локальный CodeSystem единиц измерения расширен этими семью кодами и остаётся `fragment`.
