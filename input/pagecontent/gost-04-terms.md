# 4. Термины, определения и сокращения

## 4.1 Термины и определения

В настоящем стандарте применены термины и определения по ПНСТ
995–2024 и спецификации HL7 FHIR. Для удобства чтения ниже приведены
основные понятия, используемые в настоящем стандарте.

### 4.1.1 Общие понятия

| Термин | Определение |
|---|---|
| информационное взаимодействие | Обмен данными между информационными системами, участниками или сервисами с целью передачи, получения, обработки или использования информации. |
| интероперабельность | Способность информационных систем обмениваться данными и использовать полученную информацию без дополнительного ручного преобразования смысла данных. |
| информационный объект | Представление сведения или группы связанных сведений, передаваемых или обрабатываемых информационной системой. |
| ресурсная модель данных | Способ описания данных как набора отдельных ресурсов, каждый из которых представляет самостоятельный информационный объект или часть предметной области. |
| сервисно-ориентированная архитектура | Архитектурный подход, при котором функции информационной системы предоставляются в виде сервисов с определенными интерфейсами взаимодействия. |
| прикладной интерфейс | Описанный способ взаимодействия программных компонентов или систем, позволяющий запрашивать, передавать или изменять данные. |
| руководство по реализации | Документ или машиночитаемая спецификация, устанавливающие правила применения базовой спецификации для конкретной области, страны, организации или сценария обмена. |
| национальное руководство по реализации | Руководство по реализации, устанавливающее правила применения базовой спецификации с учетом национальных требований, справочников, идентификаторов и организационной практики. |
| прикладное руководство по реализации | Руководство по реализации, уточняющее правила обмена данными для конкретного прикладного сценария, процесса или группы участников взаимодействия. |
| базовая спецификация | Исходная спецификация, устанавливающая общие модели, типы данных, ресурсы, правила и механизмы расширения, на основе которых строятся профили и руководства по реализации. |
| профиль национального уровня | Профиль, установленный национальным руководством по реализации и предназначенный для повторного использования в прикладных сценариях внутри соответствующей юрисдикции. |
| прикладный профиль | Профиль, уточняющий базовый ресурс или профиль более высокого уровня для конкретного сценария информационного взаимодействия. |

### 4.1.2 Понятия FHIR-модели

| Термин | Определение |
|---|---|
| ресурс | Основная единица представления данных в HL7 FHIR, имеющая определенную структуру, идентификатор и набор элементов. |
| экземпляр ресурса | Конкретный объект данных, созданный в соответствии со структурой ресурса и, при наличии профиля, с ограничениями этого профиля. |
| тип данных | Формальная структура для представления значения элемента ресурса, например строки, даты, идентификатора, ссылки или кодируемого понятия. |
| элемент ресурса | Именованная часть структуры ресурса или типа данных, предназначенная для хранения отдельного значения или группы связанных значений. |
| метаданные ресурса | Служебные сведения об экземпляре ресурса, включая версию, профиль, теги, признаки безопасности и иные данные сопровождения. |
| текстовое представление ресурса | Человекочитаемое представление содержимого ресурса, предназначенное для безопасной интерпретации пользователем. |
| вложенный ресурс | Ресурс, включенный внутрь другого ресурса и не имеющий самостоятельного существования вне содержащего его ресурса. |
| ссылка | Элемент, указывающий на другой ресурс или объект, с которым связан текущий ресурс. |
| идентификатор | Значение, присвоенное объекту в определенной системе идентификации и используемое для его распознавания во внешних или внутренних процессах. |
| канонический идентификатор | Устойчивый глобальный идентификатор дефиниционного артефакта, обычно представленный абсолютным URI. |
| система идентификации | Правило или пространство имен, в рамках которого выдаются и интерпретируются идентификаторы объектов. |
| система кодирования | Система, определяющая набор кодов и связанных с ними значений для представления понятий в машиночитаемом виде. |
| кодируемое понятие | Представление понятия с помощью одного или нескольких кодов, их систем кодирования и, при необходимости, текстового описания. |

### 4.1.3 Профилирование и ограничения

| Термин | Определение |
|---|---|
| профилирование | Процесс уточнения базовой структуры ресурса или типа данных путем задания дополнительных требований, ограничений, привязок и правил применения. |
| профиль ресурса | Формальное описание ограничений и правил применения ресурса для определенного контекста использования. |
| родительский профиль | Профиль или базовая структура, от которой наследуется новый профиль и ограничения которой должны сохраняться или усиливаться. |
| дочерний профиль | Профиль, созданный на основе родительского профиля или базовой структуры и вводящий дополнительные уточнения. |
| расширение | Механизм добавления к ресурсу или типу данных дополнительных сведений, отсутствующих в базовой структуре. |
| модифицирующее расширение | Расширение, изменяющее или уточняющее смысл элемента или ресурса таким образом, что его нельзя безопасно игнорировать. |
| ограничение | Формальное требование к структуре, значению, типу, кратности или способу заполнения элемента. |
| кратность | Правило, задающее минимальное и максимальное число повторений элемента в экземпляре ресурса. |
| срез | Выделенная часть повторяющегося элемента, имеющая собственные правила заполнения и ограничения. |
| дискриминатор среза | Признак или путь в данных, по которому элементы массива распределяются между срезами. |
| обязательный для поддержки элемент | Элемент, который реализация должна уметь обрабатывать, если он присутствует в экземпляре ресурса. |
| привязка к набору значений | Правило, связывающее кодируемый элемент с перечнем допустимых или рекомендуемых кодов. |
| сила привязки | Характер обязательности использования набора значений, например обязательная, расширяемая, предпочтительная или иллюстративная привязка. |
| шаблонное значение | Значение или часть значения, которое должно присутствовать в элементе и использоваться как установленный образец заполнения. |
| ограничение типа | Требование использовать для элемента определенный тип данных, профиль типа данных или профиль ресурса, на который указывает ссылка. |
| валидация | Проверка экземпляра ресурса на соответствие базовой спецификации, профилю, терминологическим привязкам и иным установленным правилам. |

### 4.1.4 Дефиниционные и терминологические артефакты

| Термин | Определение |
|---|---|
| StructureDefinition | Ресурс HL7 FHIR, описывающий структуру ресурса, типа данных, профиля или расширения. |
| ElementDefinition | Компонент StructureDefinition, описывающий отдельный элемент структуры, его тип, кратность, ограничения, привязки и другие правила. |
| NamingSystem | Ресурс HL7 FHIR, описывающий систему идентификации и связанные с ней идентификаторы, такие как URI или OID. |
| CodeSystem | Ресурс HL7 FHIR, описывающий систему кодирования, ее коды, отображаемые значения и свойства понятий. |
| ValueSet | Ресурс HL7 FHIR, задающий набор кодов из одной или нескольких систем кодирования для использования в определенном контексте. |
| snapshot-представление | Полное представление структуры профиля со всеми элементами и ограничениями, включая унаследованные правила. |
| differential-представление | Представление только тех изменений и уточнений, которые профиль вводит относительно родительской структуры. |
| набор значений | Определенный перечень кодов, допустимых, рекомендуемых или приводимых в качестве примера для кодируемого элемента. |
| справочник | Упорядоченный источник нормативных или прикладных значений, используемых для кодирования и проверки данных. |
| терминологическая система | Система кодов, понятий, справочников или наборов значений, используемая для единообразного представления смысла данных. |
| пространство идентификаторов | Область, в которой идентификаторы выдаются и интерпретируются по единым правилам и не должны конфликтовать между собой. |
