## Результаты доступа

- HTTPS портала и GitLab сначала возвращает ошибку проверки цепочки сертификатов. Диагностическое чтение без проверки сертификата: портал возвращает страницу 403; GitLab перенаправляет на `/users/sign_in`.
- Открытый API GitLab по поиску OID возвращает пустой список. Чтение Git через настроенные credentials не удалось: требуется имя пользователя, интерактивный ввод отключен. Настройки Git не менялись.
- В локальной папке Downloads найдены `Протокол консультации.pdf`, `Протокол консультации-2.pdf`, `Протокол консультации-3.pdf`. Предыдущая инициатива уже классифицировала их как отображения документов, а не руководство с XML. Они не используются вместо официального учебного примера.
- В репозитории `fhir-ru/Ru-SEMD` есть работа по лабораторному СЭМД, но в просмотренном дереве нет исходного XML консультации.

Необходимый вход: архив руководства редакции 5 с каталогами guide/xml/xsd (и схематронами, если включены), либо локальный путь к уже скачанному пакету. Значения пациента из случайных опубликованных медицинских документов не используются для создания примера.
