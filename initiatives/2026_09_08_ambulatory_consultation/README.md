# Пробный маппинг амбулаторной консультации СЭМД → RuCore

Статус: подготовка; получение руководства и исходного XML заблокировано доступом к источнику.
Дата: 2026-09-08. Исполнитель: Коган.
Ветка: `initiative/2026-09-08-ambulatory-consultation`.
Базовая версия RuCore: `0.18.0`, FHIR R5 `5.0.0`.

## Цель

Взять XML-пример из руководства СЭМД «Протокол консультации», выполнить прослеживаемое сопоставление элементов с FHIR R5/RuCore, получить document Bundle и список выявленных пробелов. Рабочее уточнение пользовательского названия «Амбулаторная консультация»: СЭМД 227, редакция 5, templateId `1.2.643.5.1.13.13.15.13.5`. Название и амбулаторный контекст должны быть подтверждены содержимым пакета.

## Границы

По прямому указанию оператора результаты находятся только в инициативе и отдельной ветке. Они не входят в официальную спецификацию, меню IG, `input/fsh`, ГОСТ и опубликованные примеры. Версия RuCore и история официального выпуска не меняются. Эта инициатива может фиксироваться в Git в своей ветке по явному поручению оператора, несмотря на общее правило `initiatives/README.md`.

## Критерии готовности

1. Зафиксированы редакция руководства, URL, версия/commit пакета (если доступны), имя XML и SHA-256 полученных файлов. XML взят из руководства, а не составлен вручную.
2. Для каждого атрибута и текстового значения выбранного XML имеется исходный XPath и решение: структурный перенос, сохранение в narrative, технические метаданные либо явная потеря/неподдержанный элемент. Одних общих строк «пациент → Patient» недостаточно.
3. Преобразование воспроизводимо; результат включает `Bundle.type=document`, Composition первым, разрешимые ссылки и необходимые ресурсы. Статусы, даты и кодирования не выдумываются.
4. Список пробелов ссылается на конкретные XPath и ограничения RuCore. Пробелы Core отделены от правил прикладного СЭМД и неполноты прототипа.
5. Проверены исходный XML доступными XSD/схематронами, FHIR-результат валидатором R5 и применимыми профилями RuCore; ограничения терминологической проверки перечислены явно.
6. Проверены сохранение идентификаторов и текста разделов, отсутствие потерь без регистрации и воспроизводимость результата.

Пока отсутствует исходный XML, критерии 1–6 не выполнены. FHIR-пример и маппинг конкретных элементов не заявляются готовыми.
